# 🌍 WanderLust 🏡

**WanderLust** is a full-stack web application that allows users to browse, book, and list vacation stays such as villas, farmhouses, and homes. It is designed to provide a seamless travel booking experience with user-friendly features, real-time map integration, secure authentication, and a responsive interface.

---

## 📌 Project Highlights

- 🏘️ Browse vacation homes by location and type
- 🧳 Add and manage your own property listings
- 🔐 Secure login using Google & GitHub OAuth
- 🗺️ View real-time property locations using Mapbox
- 📷 Upload images and store them via Cloudinary
- 📱 Fully responsive layout with modern UI
- 📆 Integrated booking system with user reviews

---

## 🛠️ Tech Stack

### 🌐 Frontend
- **Languages & Tools**: HTML, CSS, JavaScript, EJS
- **Frameworks**: React.js, Bootstrap
- **APIs & Integrations**:
  - Mapbox – for location mapping
  - Cloudinary – for image hosting

### 🔧 Backend
- **Runtime & Framework**: Node.js, Express.js
- **Authentication**: Passport.js, JWT
- **Session Management**: Express-Session, Cookies, Connect-Mongo
- **Validation**: Joi for schema validation

### 🗄️ Database
- **DBMS**: MongoDB Atlas
- **ODM**: Mongoose for schema modeling

---

## 🌟 Key Features

- 🔐 **Authentication**:
  - Google OAuth & GitHub OAuth login
  - Secure sessions using JWT & cookies

- 🏠 **Property Management**:
  - Users can list, edit, or delete their own properties
  - Upload multiple images using Multer and Cloudinary

- 🔍 **Search & Filter**:
  - Advanced search options based on location and price

- 📅 **Booking System**:
  - Book properties with automatic availability checks

- ⭐ **Ratings & Reviews**:
  - Leave feedback and rate stays after visits

- 📍 **Map Integration**:
  - Mapbox to show exact property location

- 🎨 **UI/UX Design**:
  - Responsive, mobile-friendly design
  - Clean interface using Bootstrap and custom CSS

- 🧩 **Architecture**:
  - MVC (Model-View-Controller) architecture for scalability
  - EJS templates for dynamic rendering
  - Modular routing for maintainability
